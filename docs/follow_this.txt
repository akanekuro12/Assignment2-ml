The WEPAStacks dataset represents 89 days of operations in a real finished-goods warehouse. Products arrive from four production lines through four inbound points. Each arriving pallet must be collected by a warehouse vehicle and moved into storage. Pallets requested for shipping are later moved from storage to one of ten outbound points.
The dataset contains three files. 1_layout.csv describes the warehouse layout, including storage areas, aisles and inbound and outbound points. 2_orders.json contains approximately 400,000 pallet delivery and retrieval events and is the main file used in this project. 3_initial_fill_lvl.json describes the inventory stored in the warehouse at the beginning of the simulation.
Each order event contains the event type, product identifier, arrival time, dock number, batch number and week number. This project focuses only on delivery events at inbound points 1 to 4. The data is cleaned by checking missing values, correcting data types, validating the dock and time values, and sorting the events by arrival time. The arrival time is then divided into 15-minute intervals, and the number of arriving pallets at each inbound point is calculated.
Because the dataset does not contain inbound queue information, the queue at each inbound point is simulated using the number of arriving pallets and the number of pallets removed by warehouse vehicles. An MLP uses the current buffer utilisation and recent pallet-arrival rates to predict whether an inbound point will become congested during the next 60 minutes.
